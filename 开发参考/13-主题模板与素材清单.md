## 二、`theme_manifest.json`（完整内容，直接改）

```json
{
  "schema_version": "1.0",
  "theme": {
    "id": "myskin",
    "name": "MYSKIN",
    "version": "1.0.0",
    "author": "your-name",
    "description": "一句话描述你的主题"
  },
  "compatibility": {
    "min_firmware": "1.2.0",
    "max_firmware": "2.x.x"
  },
  "colors": {
    "bg": "0x0B0D10",
    "ring": "0x4FC3F7",
    "arc_track": "0x1B2733",
    "arc_indicator": "0x4FC3F7",
    "text_primary": "0xE8F4FF",
    "text_secondary": "0x6E8CA0",
    "needle": "0xFF5252",
    "panel": "0x141A21"
  },
  "assets": {
    "ring": "assets/ring.png",
    "dial": "assets/dial.png",
    "needle": "assets/needle.png",
    "needle_pivot_x": 24,
    "needle_pivot_y": 12
  },
  "pages": {
    "system_pages": [
      "logo", "intro", "boot_video", "settings", "ota",
      "vehicle_select", "bluetooth_pair", "wifi_config",
      "chart_alarm", "chart_config"
    ],
    "theme_pages": [
      {
        "id": "main_gauge",
        "type": "custom_layout",
        "replaces": ["page_rpm", "page_boost", "page_multi_gauge"]
      }
    ]
  }
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `theme.id` | ✅ | 小写字母/数字/`-`/`_`，建议与文件夹名一致 |
| `theme.name` | ✅ | 设备上显示的名字，大写 ASCII/数字，1~10 字符 |
| `compatibility` | ❌ | 两个字段都去掉也行（若加载被拒，先试着删掉这一段） |
| `colors.*` | ✅ | **8 个全部必填**，格式是**字符串** `"0xRRGGBB"`（不是 TOML 数字） |
| `assets.*` | ❌ | 有图才写；没写的项自动回退为代码绘制 + 对应颜色 |
| `assets.needle_pivot_x/y` | ❌ | 指针图的旋转中心像素坐标（指针根部轴心）。**用官方参考图就是 24 / 12** |
| `pages` | ❌ | 不写就没有自定义页面，只有配色生效 |

> ⚠️ **不要把 8 个颜色抄成 TOML 数字格式**（那是"编译进固件的内置主题"用的 `theme.toml`，两套格式不一样）。

## 三、`layout.json`（可选，自定义主表页）

只有想自己排布 `main_gauge` 页的元素时才需要。示例（增压表 + 机油压力条）：

```json
{
  "page_id": "main_gauge",
  "background_color": "0x0B0D10",
  "elements": [
    {
      "type": "arc", "id": "boost_arc",
      "x": 30, "y": 30, "width": 300, "height": 300,
      "start_angle": 135, "end_angle": 45, "rotation": 0,
      "data_source": "obd.boost",
      "range_min": -70, "range_max": 250,
      "color": "0x4FC3F7", "bg_color": "0x1B2733", "line_width": 20
    },
    {
      "type": "label", "id": "value",
      "x": 180, "y": 130, "align": "center",
      "data_source": "obd.rpm",
      "format": "%d", "divisor": 1,
      "color": "0xE8F4FF", "font_size": 48
    },
    {
      "type": "bar", "id": "oil_bar",
      "x": 30, "y": 280, "width": 300, "height": 30,
      "data_source": "obd.oil_pressure",
      "range_min": 0, "range_max": 100,
      "color": "0x4FC3F7", "bg_color": "0x1B2733", "segments": 10
    }
  ]
}
```

三种元素类型：`arc`（弧线仪表）/ `label`（数值或文字）/ `bar`（条形）。
`data_source` 可用值见 `themes/example_boost_oil/layout.json` 与主题引擎文档。

> ⚠️ **阿特兹是自吸，`obd.boost` 恒为 0** —— 自定义布局请用 `obd.rpm` / `obd.speed` / `obd.coolant` / `obd.oil_temp` 这些。

## 四、素材绘制清单 ⭐（你要画的就是这三张）

### 4.1 参考素材已经下好了，**先打开看**

| 文件 | 尺寸 | 大小 | 用途 |
|---|---|---|---|
| `D:\AtzGauge\mytheme\assets\ring.png` | 360×360 | 31 KB | 表框参考 |
| `D:\AtzGauge\mytheme\assets\needle.png` | 176×24 | 2 KB | 指针参考 |
| `D:\AtzGauge\mytheme\assets\dial.png` | 360×360 | 20 KB | 表盘底参考 |

**这三张是官方给的"尺寸和朝向都正确"的样板**：打开看一眼就明白要画什么，然后照着尺寸换成你自己的。

### 4.2 官方参考素材的实际样子（我实测看过）

**ring.png（360×360，带 alpha）**
- 中间**完全透明**，只在边缘有一圈约 **8~10 px** 的浅灰实心圆环
- 环**不是连续圆**：被等分成若干段，段与段之间有**小刻度缺口**（每 30° 左右一个）
- 环的外缘大致贴到画布边缘（留 2~4 px 余量）

**needle.png（176×24，带 alpha）**
- **朝右（东）**，左端粗、右端收成尖
- 左端约 `x=24` 处有一个**圆帽/轴心**（浅灰圆环 + 深色圆心），半径约 12 px
- 所以旋转中心就是 **`needle_pivot_x = 24, needle_pivot_y = 12`**
- ⚠️ **画成朝上就整体偏 90°** —— LVGL 绕 pivot 旋转，角度 0 = 原样绘制

**dial.png（360×360，实心）**
- 整块背景，**不透明**（透明通道会被忽略，它是最底层）
- 建议**中心区域保持低对比/干净** —— 大号数字、弧线、单位文字都压在上面，底图太花会看不清

### 4.3 素材规格硬指标

| 素材 | 尺寸 | 透明通道 | 编译后占用 | 替换掉什么 |
|---|---|---|---|---|
| `ring` | **必须正好 360×360** | **需要**（中间镂空） | 约 380 KB | 外圈表框（原为代码画的圆环） |
| `needle` | ≤360×360（参考 176×24） | **需要** | 宽×高×3 B | 指针页的指针（原为代码画的线） |
| `dial` | **必须正好 360×360** | 忽略 | 约 253 KB | 所有页面背景（原为纯 `bg` 色） |

- 尺寸差一个像素，`pack_theme.py` **直接抛错**：`Image xxx must be 360x360, got (w, h)`
- 导出用 **PNG-24 + Alpha**（不要 JPG、不要索引色 PNG）
- 工具随意：Photoshop / GIMP / Krita / Affinity / Illustrator 导出 PNG 都行

### 4.4 画之前的三个设计建议

1. **中心留白**：360×360 里，中间约 240×240 是数值和弧线的地盘，别在那里堆细节
2. **圆屏会裁角**：四角在圆屏上根本看不见，重要内容留在直径 360 的圆内
3. **夜间可读性**：`bg` 与 `dial` 都用深色（这块屏亮底夜里非常晃眼），`arc_indicator` 必须**明显亮于** `arc_track`

| `arc_track` | `0x333333` | `0x3A2E10` | `0x10303C` |

| `text_primary` | `0xFFFFFF` | `0xFFD27A` | `0xBFEFFF` |

> 注意 **AMBER 的 `ring` 与 `arc_indicator` 同色**、**DEFAULT 的 `ring` 与 `arc_indicator` 都是纯白** —— 效果上没问题，但你自己配的时候不建议让 `arc_indicator` 和 `arc_track` 太接近。

**语义色动不了**（全局固定，任何主题都不许改）：

| 宏 | 值 | 含义 |
|---|---|---|
| `UI_SEM_ALERT` | `0xFF4D4D` | 报警/超阈值文字 |
| `UI_SEM_FLASH` | `0xFF0000` | 转速报警全屏闪烁 |
| `UI_SEM_ON` | `0x06D6A0` | 开关 ON / 正常 |
| `UI_SEM_WARN` | `0xFFD166` | 注意（机油压力等） |

装了车，红必须永远意味着"出事了"——这是刻意设计，不是遗漏。

## 六、打包 + 烧录（两条命令）

```cmd
:: 1) 打包成 4MB blob（需要 Pillow：pip install Pillow）
python D:\AtzGauge\obd_brz_gauge\src\tools\theme_packer\pack_theme.py D:\AtzGauge\mytheme D:\AtzGauge\mytheme\theme.bin

:: 2) 烧到 theme_0 分区（写入区间 0x620000 ~ 0xA1FFFF，不碰 0xA20000 的 bootmedia）
python -m esptool --chip esp32s3 -p COM3 write-flash --flash-mode dio --flash-freq 80m --flash-size 16MB 0x620000 D:\AtzGauge\mytheme\theme.bin
```

**恢复内置主题**（想退回出厂外观时）：

```cmd
python -m esptool --chip esp32s3 -p COM3 erase-region 0x620000 0x400000
```

擦掉即可，设备下次开机自动回退 `DEFAULT`。已在 2026-09 实测通过（0.5 秒擦完）。

| **中文** | ESP-IDF 工具链对非 ASCII 路径脆弱（微雪官方明确警告中文用户名会导致编译错误） |
| **空格** | CMake / Ninja / 各类脚本对空格处理不完善，常见报错 |

## 二·补、🔒 私密值放哪：`atz_local.h`（不进 git）

仓库只放**公开占位值**，口令等私密值放本机的 `atz_local.h`。这样仓库可以随时公开
（GitHub / 分享 / 换机器），不会带出任何凭据。

| 项 | 值 |
|---|---|
| 私密头路径 | `xiaozhi-esp32\src\main\boards\waveshare\esp32-s3-touch-lcd-1.85-atzgauge\atz_local.h` |
| 是否进 git | **否**（`.gitignore` 里 `**/atz_local.h` 已排除；`gen-mods-kit.mjs` 也忽略了它） |
| 模板 | `开发参考\atz_local.h.example`（复制过去改名即可） |
| 覆盖机制 | `atz_ui_config.h` **最前面**用 `__has_include` 探测并 include；默认值一律写成 `#ifndef` 兜底 |
| 当前覆盖内容 | `ATZ_DEBUG_TOKEN`（调试写接口的 `&key=` 口令） |

**★ 教训（2026-09-17，缺陷 #40）**：`__has_include` 的 include **必须放在所有默认值之前**。
第一版写在文件末尾，等于"先定义后 include" → 编译器报
`'ATZ_DEBUG_TOKEN' redefined [-Werror]`，而本工程开了 `-Werror`，整个构建直接失败。
正确顺序是：**私密头 → 默认值（#ifndef 包着）→ 其余配置**。

**工具怎么拿口令**（不用手工同步）：

| 工具 | token 读取顺序 |
|---|---|
| `tools/emoji-kit.mjs`、`tools/sim-console.mjs` | 环境变量 `ATZ_DEBUG_TOKEN` → `atz_local.h` → `atz_ui_config.h` → 公开占位值 |

设备 IP：命令行 `--device <IP>` → 环境变量 `ATZ_DEVICE` → 脚本里的公开占位值。

## 二·补2、💻 串口只有一处配置 + 复制到另一台电脑

### 串口：改 `PORT.txt` 就够了（2026-09-17 新增）

以前 6 个脚本各自写死 `COM3`，换机器要改 6 处。现在统一走 `tools\atz-port.ps1`：

| 优先级 | 来源 | 场景 |
|---|---|---|
| 1 | 脚本参数 `-Port COM5` | 临时指定 |
| 2 | 环境变量 `ATZ_PORT` | 会话级，`$env:ATZ_PORT='COM5'` |
| 3 | **`<工作区>\PORT.txt`** | **换电脑就改这一个文件** |
| 4 | 兜底 `COM3` | 本机默认 |

`PORT.txt` 用 `Set-Content PORT.txt 'COM5'` 写一行即可（不要加 BOM，脚本按 ASCII 读第一行非注释内容）。
它**不进 git**（每台机器不同）。

> ⚠️ `.ps1` 里 `param()` 必须是**第一条语句**，所以 `boot-log.ps1` 是"先 param、后 dot-source 补默认值"，
> 不能写成 `param([string]$Port = (Get-AtzPort))` —— 那会在 param 之前 dot-source，直接语法错误。

### 复制到笔记本：`tools\make-laptop-kit.ps1`

```powershell
# 只带"能烧能抓日志"的最小集（约 50 MB），串口预置成 COM7
powershell -NoProfile -ExecutionPolicy Bypass -File tools\make-laptop-kit.ps1 -Dest E:\AtzGauge-kit -ComPort COM7
# 加 -Profile build（818 MB，能编译）/ -Profile full（1.4 GB，含 build 与 .git）
# 加 -WhatIf 只看清单不复制
```

| 方案 | 体积（实测） | 笔记本上能做什么 |
|---|---|---|
| `minimal`（默认） | **49.6 MB** | 刷两个项目的固件 + 抓日志 + 换表情包（需 Node）+ 那 34 MB 不可再生的整片备份 |
| `build` | 818 MB | 以上 + 完整源码 + `managed_components`（省一次 735 MB 下载）→ 装好 IDF 就能编译 |
| `full` | 1.4 GB | 以上 + `build\`（**仅当目标路径完全相同**才有意义）+ `.git` |

脚本会：**护栏**（拒绝中文/带空格的路径 —— ESP-IDF 对这类路径脆弱，本项目踩过）→ 按清单 robocopy →
生成目标机的 `PORT.txt` 与 `笔记本使用说明.md` → **逐组校验文件数与字节数**，不一致就报错。

**三条铁律**（复制到别处时）：路径放 **`D:\AtzGauge` 这种纯 ASCII 无空格位置**；`build\` 只在同路径下可用
（`CMakeCache.txt` 里烙的是绝对路径）；**ESP-IDF 永远不能复制**（6.75 GB 的工具链二进制 + 路径烙死，
必须在目标机重跑 `install.ps1`）。

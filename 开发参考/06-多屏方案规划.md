# 多屏方案规划（1 小智AI + 2~3 仪表）

> 硬件基线：微雪 ESP32-S3-LCD-1.85 ×N + Vgate iCar Pro 2S ×1
> 软件基线：obd_brz_gauge（主从架构）+ xiaozhi-esp32
> 日期：本会话

---

## 一、结论先行

| 方案 | 组成 | 与项目架构匹配度 |
|---|---|---|
| **3 屏**（1 AI + 2 仪表） | 1 主表 + 2 从表 | ✅ **正好对应项目已验证的"三连表"** |
| **4 屏**（1 AI + 3 仪表） | 1 主表 + 3 从表 | ⚠️ 超出已测试范围，需确认从表上限 |

### ⚠️ 强烈建议：不要一次买 4 块

**风险**：整套方案成立的前提是「固件能在阿特兹上读到数据」，而这一步**尚未验证**。
若协议/PID 不匹配，手上就是一堆砖。

**而加屏是随时能加的**：主从架构已内置，以后加板只需烧从表固件 + 设置角色，
**不用改代码、不用动 Vgate、不用动主表**。

---

## 二、架构（3 屏方案）

```
              [车 OBD 口]
                   │ 有线
           [Vgate iCar Pro 2S]
                   │ BLE（唯一客户端）
                   ▼
     ┌─────────────────────────────┐
     │ ① 仪表板（微雪 1.85）        │
     │   角色：MASTER               │
     │   · 读 OBD                   │
     │   · 显示仪表                 │
     │   · ESP-NOW 广播             │
     └─────────────────────────────┘
                   │ ESP-NOW（广播）
        ┌──────────┴──────────┐
        ▼                     ▼
 ┌──────────────┐    ┌──────────────────┐
 │ ② 仪表板      │    │ ③ 小智AI 板       │
 │  角色：SLAVE  │    │  角色：SLAVE      │
 │  · 收数据     │    │  · 收数据         │
 │  · 显示仪表   │    │  · 阈值判断       │
 │              │    │  · 语音提示       │
 └──────────────┘    └──────────────────┘
```

**关键点**：小智AI 板在本架构里**也是一块从表**，所以 1 主 + 2 从 = 正好是项目验证过的三连表。

## 四、推荐推进顺序

| 阶段 | 买什么 | 验证什么 | 是否可以停 |
|---|---|---|---|
| **1️⃣ 现在** | 1 块微雪板（已定） | 烧固件 → 上车读到转速水温 | ✅ 可停 |
| 2️⃣ | — | 车上稳定运行几次，确认值得投入 | ✅ 可停 |
| 3️⃣ | +1 块板 | 主从联动（1主1从） | ✅ 可停 |
| 4️⃣ | +1 块板 或便宜板 | 小智AI 当从表，语音提示 | ✅ 可停 |
| 5️⃣ | 视情况再加 | 三联表 / 四联表 | — |

**每阶段都能独立验证，不会白花钱。**

## 五、需要确认的技术点

- [ ] **主表支持的从表上限**：官方只验证了三连表（1主+2从）。1主+3从需要看 `espnow_link.c` 里的从表计数逻辑
- [ ] **ESP-NOW 信道**：小智AI 板连路由器上云会锁定信道，ESP-NOW 必须用同一信道
- [ ] **配对流程**：从表通过 BLE 配对拿主表 MAC，小智AI 板需短暂占用 BLE
- [ ] **音频仲裁**：告警播报与用户对话不能同时出声

## 六、供电

| 屏数 | 估算功耗 | 建议供电 |
|---|---|---|
| 1 屏 | 5V / 0.3~0.5A | 单个 USB 车充 |
| 3 屏 | 5V / 1~1.5A | 5V/3A 车充或降压模块 |
| 4 屏 | 5V / 1.2~2A | **5V/4A** 车充或降压模块 |

**注意**：ESP-NOW 只传数据不传电，每块板都要独立 5V 供电，不能串联。

## 七、实际问题提醒

1. **安装位置**：仓库的三联表座是为 BRZ 设计的，阿特兹需自制支架；4 块屏在阿特兹仪表台上会很挤
2. **走线**：3~4 根 USB-C 线需要规划走线路径，建议走 A 柱/仪表台缝隙
3. **散热**：密闭表座内多块板 + 屏幕背光发热，夏天车内高温需注意
4. **要不要电池**：板子有 3.7V 锂电接口，但车内高温下锂电池有安全风险，建议硬接供电

## 八、分工建议（每块屏显示什么）

| 屏 | 内容 |
|---|---|
| ① 仪表板（主） | 转速 RPM（主表必须连 Vgate） |
| ② 仪表板（从） | 水温 / 油温 |
| ③ 小智AI（从） | AI 表情界面 + 语音提示 |
| （④ 若加） | 电压 / 进气温度 / 负荷 |

> 阿特兹是自然吸气，**没有涡轮增压表**，所以不用预留 boost 显示。

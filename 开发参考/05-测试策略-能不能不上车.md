# 测试策略：能不能不上车测？（台式机用户版）

> 场景：开发者只有台式机，车停在别处
> 结论：**80% 的调试能在家完成，只有"真实数据"必须上车**

---

## 一、核心认知：台式机只在"烧录"时需要

板子烧好固件后**独立运行**，只要有电就行。所以不需要把电脑搬到车上。

```
在家：台式机烧录固件
  ↓
拿板子去车上（USB 充电宝供电，不带电脑）
  ↓
插 Vgate，看屏幕效果（拍视频记录）
  ↓
有问题 → 带回家重新烧 → 再去车上
```

| 测试项 | 需要车？ | 在哪做 | 说明 |
|---|---|---|---|

| 触摸、按键、翻页 | ❌ | 家 | — |
| 主题切换 | ❌ | 家 | — |

| **连接 Vgate / ELM327 初始化** | ❌ | **家** | AT 命令能通 |
| 仪表 UI 渲染 | ❌ | 家 | 无数据，显示 0 |
| 断电重启 / 自恢复 | ❌ | 家（插拔电源） | — |

| 蓝牙重连自愈 | ✅ | **车上** | 需要真实适配器行为 |

## 三、在家给 Vgate 供电的详细做法

Vgate iCar Pro 2S 从 **OBD 第 16 脚取 12V** 供电。

### 需要的材料
| 材料 | 说明 | 参考价 |
|---|---|---|
| OBD2 母头插座（带线） | 淘宝搜"OBD2 母座 带线" | ¥5~10 |
| 12V 电源适配器 1A 以上 | 或可调电源 | ¥10~20 |
| 万用表 | 确认电压和极性 | ¥30~50 |

### 接线

| OBD 脚 | 接到 |
|---|---|
| 第 **16** 脚 | 12V 电源**正极** |
| 第 **4**（或 5）脚 | 12V 电源**负极 / GND** |

### ⚠️ 安全要点
1. **正负极绝对不能接反**，接反可能烧毁 Vgate
2. 接之前先用万用表确认适配器输出是 12V 且极性正确
3. 通电后 Vgate 指示灯亮起 = 正常

### 验证效果
通电后你可以：
- 用手机蓝牙搜到 Vgate 设备
- 用板子（仪表固件）的 BLE SCAN 页面扫到并连接
- 在串口日志看到 ELM327 初始化命令交互成功
- 但 PID 查询会返回 `NO DATA`（家里没有 ECU 应答）

## 四、进阶：用第二块 ESP32 假冒 ELM327（BLE 版）

如果想让**仪表指针在家也动起来**，可以用第二块 ESP32 刷一个"假 ELM327 BLE 外设"：

- 广播与 Vgate 相同的 BLE 服务 / 特征值 UUID（UUID 从 `main/bsp_obd_dsp/elm327_ble_client.c` 里抄）
- 收到 `01 0C` 返回假转速、`01 0D` 返回假车速、`01 05` 返回假水温……
- 让数值缓慢变化，指针就会动

**优点**：在家就能完整调 UI、调报警阈值、调动画
**代价**：要写代码，属于进阶操作

## 五、关于仓库里的 tools/fake_elm327.py（更正说明）

⚠️ **注意区分**：仓库里的 `tools/fake_elm327.py` **不是** BLE 模拟器，**不能**用来测仪表固件。

它的真实用途：
- 是一个 **WiFi / TCP** 的伪 ELM327 服务器（默认监听 `0.0.0.0:35000`）
- 让**手机 App**（Car Scanner / Torque）通过 WiFi 连上来
- 记录 App 发出的**每一条请求**（AT 命令、Mode 01/09/21/22 的 PID）
- 配合 `tools/analyze_probe.py` 做**PID 与公式的逆向分析**

**用途场景**：想搞清楚某个车型有哪些私有 PID、公式是什么时使用，属于**开发者的逆向工具**，不是仪表固件的测试替身。

## 六、固件更新：OTA 无线升级

obd_brz_gauge 支持 OTA 升级：
- `main/app_obd_dsp/ota_update_ble.c`（BLE OTA）
- `main/app_obd_dsp/ota_wifi_server.c`（WiFi OTA）
- 配套手机 App：`android_app/app-debug.apk`

**流程**：
| 阶段 | 方式 |
|---|---|
| 首次烧录 | 必须 USB + 台式机 |
| 后续升级 | 手机 App 无线 OTA（**板子不用从车上拆下来**） |

## 七、推荐工作流

| 步骤 | 地点 | 做什么 |
|---|---|---|
| 1 | 家 | 台式机烧录固件 |
| 2 | 家 | 给 Vgate 供 12V，验证 BLE 扫描 + 连接 + 初始化 |
| 3 | 家 | 检查 UI 显示、触摸、切页、主题 |
| 4 | 车上 | 插 OBD，验证真实数据（先 OBD2 Generic，再 MX-5 ND） |
| 5 | 车上 | 记录现象（拍视频 / 串口日志） |
| 6 | 家 | 按现象改代码 → 烧录 或 手机 OTA |
| 7 | 反复 4~6 | 直到稳定 |

## 八、小结

| 问题 | 答案 |
|---|---|
| 必须到车上测吗？ | 不需要，**只有"真实数据"必须上车** |
| 台式机是障碍吗？ | ❌ 不是，电脑只在烧录时需要 |
| 车上测试要带电脑吗？ | ❌ 不用，USB 充电宝供电即可 |
| 能在家测蓝牙连接吗？ | ✅ 能，给 Vgate 供 12V 就行 |
| 能在家看到指针动吗？ | 需要第二块 ESP32 假冒 ELM327（进阶） |
| 改了代码必须拆板子吗？ | ❌ 不用，支持手机 OTA |

# 自建小智服务端 · NAS 网络条件指南

> 核心结论：**服务端不需要公网 IP，需要的是「设备能连到服务器」。**

---

## 一、关键认知：ESP32 是主动外连的客户端

```
ESP32 设备  ──主动发起连接──▶  服务器（你的 NAS）
  (客户端)                        (服务端)
```

设备**主动往外连**，不是等服务器来连它。所以判断标准是"设备能不能连到服务器"，
而不是"服务器有没有公网 IP"。

| 场景 | 需要公网吗 | 用什么地址 |
|---|---|---|
| ESP32 和 NAS **同一局域网** | ❌ **不需要** | 内网 IP，如 `ws://192.168.1.100:8000/xiaozhi/v1/` |
| ESP32 在车里（手机热点），NAS 在家 | ✅ **需要**公网可达 | 公网 IP + 端口转发，或隧道，或 IPv6 |
| ESP32 在别处但能连回家里的 VPN | ❌ 不需要 | 但 ESP32 跑不了 VPN 客户端（见下） |

> ✅ **只在家玩的话，NAS 完全不需要公网 IP。**

---

## 二、怎么查有没有公网 IP

### 方法 A：对比法（最可靠）

**第 1 步**：SSH 登录 NAS，执行

```bash
curl -s ip.sb
```

记下这个"外网看到的 IP"。

**第 2 步**：登录路由器管理页（一般 `192.168.1.1`）→ 找 **WAN / 外网状态** → 看那串 IP。

**第 3 步**：对比

| 结果 | 判断 |
|---|---|
| 两个**一样** | ✅ 有公网 IP |
| **不一样** | ❌ 运营商 NAT（大内网） |

### 方法 B：看 IP 段（快速判断）

路由器 WAN 口 IP 落在这些段 = 内网/运营商 NAT：

| IP 段 | 含义 |
|---|---|
| `10.x.x.x` | 内网 |
| `100.64.x.x` ~ `100.127.x.x` | **运营商 CGNAT（最常见）** |
| `172.16.x.x` ~ `172.31.x.x` | 内网 |
| `192.168.x.x` | 内网 |

### 方法 C：查 IPv6（重要补充）

```bash
curl -s -6 ip.sb
```

有返回 = 有 IPv6。国内电信/联通/移动很多宽带都给了 **IPv6 公网地址**，
**IPv6 天然公网可达**，可以作为没有 IPv4 公网时的替代方案。

⚠️ 但要求**连接的两端都有 IPv6**：
- NAS 侧：家里的宽带要有 IPv6（多数已有）
- 车侧：手机热点的移动网络也要有 IPv6（国内移动网络 IPv6 普及率很高）

## 三、没有公网 IP 怎么办

| 方案 | 说明 | 成本 | 适合 |
|---|---|---|---|
| **① 只在家用** | 设备与 NAS 同局域网，直接内网 IP | ¥0 | ⭐ 最简单 |
| **② 用车载场景就用官方服务器** | 告警走本地音频，问答走官方 | ¥0 | ⭐ **推荐** |
| **③ IPv6 直连** | 双方都有 IPv6 时可直接连 | ¥0 | 有条件时很好 |
| **④ 内网穿透 frp** | 需要一台**有公网 IP 的小 VPS** 做中转 | ¥10~30/月 | 想自建又要外网 |
| **⑤ Cloudflare Tunnel** | 需要域名 + Cloudflare 账号，免费 | ¥0（域名费） | 愿意折腾 |

### ⚠️ Tailscale / ZeroTier 这类"异地组网"不能用

虽然它们能让你在外网访问家里的 NAS，但**需要设备装客户端**。
**ESP32 跑不了 Tailscale/ZeroTier**，所以这条路对小智设备不成立。

---

## 四、有公网 IP 也还有两个坑

1. **动态 IP**：家宽的公网 IP 通常**会变**，需要配 DDNS（动态域名）把域名指向变化的 IP
2. **端口封禁**：国内运营商一般**封禁家宽的 80 / 443 入站**（且需备案）。
   → 小智服务端用**非标准端口**（如 8000/8003）通常没问题，配置时避开 80/443

## 五、对本项目的实际建议

| 需求 | 建议 | 需要 NAS 公网吗 |
|---|---|---|
| **车载告警**（水温过高） | 本地预录音频 | ❌ 完全不需要服务端 |
| **语音问答**（在家） | NAS 自建，内网 IP | ❌ 不需要 |
| **语音问答**（在车里） | 用官方 xiaozhi.me | ❌ 不需要自建 |
| 想车载也用自建 | 需公网/IPv6/隧道 | ✅ 需要 |

### 推荐路径

```
先别管自建！
  ├── 在家：想自建就自建（内网 IP，零门槛）
  └── 车里：用官方服务器 + 告警走本地音频
```

**你的 NAS 有没有公网，其实不影响这个项目能不能做。**
先把手上的板子跑通，比什么都实在。

## 六、快速自检清单

在 NAS 上执行：

```bash
# 1. 外网看到的 IP
curl -s ip.sb

# 2. 本机网卡地址（看内网 IP 和有无 IPv6）
ip addr show          # Linux
# 或
ifconfig

# 3. 有没有 IPv6
curl -s -6 ip.sb

# 4. 和路由器 WAN 口 IP 对比 → 判断是否公网
```

| 检查结果 | 结论 |
|---|---|
| `curl -s ip.sb` == 路由器 WAN IP | ✅ 有公网 IPv4 |
| 不相等 | ❌ 运营商 NAT，考虑 IPv6 或隧道 |
| `curl -s -6 ip.sb` 有返回 | ✅ 有 IPv6，可作为替代方案 |

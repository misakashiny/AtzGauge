## 一、整条 AI 链路的 7 段

```
① 语音输入（麦克风）
② 本地唤醒词（离线）
③ 录音 + Opus 编码 → 上云
④ 云端 ASR（语音转文字）
⑤ 云端 LLM（生成回复 + 情绪；工具调用走 MCP）
⑥ 云端 TTS（文字转语音）→ 下行
⑦ 设备播放 + 屏幕表情 + 字幕
```

官方页重点讲 ②④⑤⑥；①③⑦ 属于固件/硬件层。

## 二、语音唤醒（WakeNet）

| 项 | 官方说法 |
|---|---|
| 引擎 | 乐鑫官方 Wake Word Engine（ESP-SR） |
| 默认唤醒词 | "你好小智" |
| 可选 | **26+ 种官方词汇**：中文（"你好小智"/"小智助手"/"智能管家"）、英文（"Hi ESP"/"Hello World"/"Smart Home"）、日文（"コンニチワ"/"スマート"）、韩文（"안녕하세요"/"스마트"） |
| 响应 | < 200 ms |
| 待机功耗 | < 5 mA |
| 联网 | **完全离线**，不需要网络 |

配置（官方写法）：
```bash
idf.py menuconfig
# Component config → ESP Speech Recognition → Wake Word Model Selection
```

## 三、语音识别（ASR）

| 项 | 官方说法 |
|---|---|
| 语言 | 中文（普通话/粤语）、英语、日语、韩语、俄语 |
| 识别率 | 中文 > 95%，英文 > 93% |
| 音频 | **16 kHz、16 bit PCM**（上行按协议编码，默认 Opus） |
| 离线/在线 | 混合：关键词离线，复杂语句在线 |

### 多语言本地化（v2.0 新增 17 种，共 25+）

**资源包结构**（每语言约 150 KB，按需编译；运行时当前语言约占 50 KB RAM）：

```
main/assets/locales/<lang>/
├── 0.ogg ~ 9.ogg     数字语音
├── welcome.ogg       欢迎
├── activation.ogg    激活成功
├── wificonfig.ogg    WiFi 配置提示
├── upgrade.ogg       升级
├── err_pin.ogg       PIN 错误
├── err_reg.ogg       注册错误
└── language.json     语言元数据
```

**分档**

| 档 | 语言 |
|---|---|
| Tier 1（优先优化） | 中文、英语、日语、俄语 |
| Tier 2（完整支持） | 西班牙语、法语、德语、韩语 |
| Tier 3（基础支持） | 保加利亚语、加泰罗尼亚语、丹麦语、希腊语、波斯语、菲律宾语、希伯来语、克罗地亚语、匈牙利语、马来语、挪威语、荷兰语、斯洛伐克语、斯洛文尼亚语、塞尔维亚语、瑞典语（等 17 种） |

配置：`CONFIG_XIAOZHI_LANGUAGE="zh-CN"`，或 menuconfig
→ `Xiaozhi Assistant → Language Settings → Select Language`。

> 官方提示：复杂的多语言混合识别依赖云端 ASR，建议网络稳定。

## 四、大模型（云端可选）

| AI 模型 | 提供商 | 特色能力 | 集成成本 |
|---|---|---|---|
| DeepSeek-V3 | DeepSeek | 数学推理 / 代码生成 | 低 |
| Qwen-Max | 阿里云 | 中文理解 / 多模态 | 中 |
| Doubao-Pro | 字节跳动 | 对话生成 / 创作 | 中 |
| ChatGPT-4o | OpenAI | 通用智能 / 逻辑推理 | 高 |
| Gemini | Google | 多模态 / 实时交互 | 中高 |

> 选型属**服务端**配置，与固件无关。

## 五、端侧 AI（官方标注"规划功能"）

- TensorFlow Lite，量化后 1–10 MB 轻量模型，简单指令 < 100 ms。
- 官方定位：简单指令走端侧、复杂对话走云端（"混合推理"）。

## 六、AI 视觉（v2.0 新增）

- 相机代码重构（`esp32_camera.cc` 到 935 行）、接口标准化、支持 QVGA~1080p。
- 官方称：帧率 +30%、延迟 −50%、PSRAM 占用优化。
- 支持模组：OV2640 / OV3660 / OV5640 / GC032A。
- 初始化示例里用到 `fb_count = 2`（双缓冲）与 `CAMERA_GRAB_LATEST`（v2.0 新增抓取模式）。

## 七、性能指标那一节

官方给的是一组"整机 + 官方云服务"的典型值（唤醒 <200 ms、中文识别 >95%、
视觉帧率/延迟提升、待机 <5 mA 等）。**它描述的不是开源固件单独跑出来的数字**，
要评估自己的设备，用设备自己的体感/日志（我们项目是 `/health`、`/perf`）。

## 八、与本项目的关系（速览）

| 官方能力 | 我们这边 |
|---|---|
| 唤醒词 | ✓ 用上了（离线），模型 `srmodels.bin` 存在 **assets 分区** |
| ASR/LLM/TTS | ✓ 走服务端；模型选型在服务端 |
| 工具调用（MCP） | ✓ 我们全部语音功能都靠它（`self.car.*` / `self.ui.*`） |
| Emoji 心情 | ✓ 用上了，21 个情绪；对照表见 `emotion_对照表.md` |
| 运行时换素材 | ✓ 用上了（`assets/download_url` 机制） |
| 端侧 AI | ✗ 不可行（SRAM 只剩 ~13 KB） |
| 相机/视觉 | ✗ 无摄像头 |
| 多语言 | ⚠️ 目前只有 zh-CN |
| BluFi 配网 | ⚠️ 可用，但当前走声波配网 |

详细对照与理由见 `../../23-上游AI能力特性（整理与本项目标注）.md`。

## 二、AtzGauge 用到的部分（速查，避免翻长文）

| 需求 | 看哪份 | 关键结论 |
|---|---|---|
| 板型怎么注册 | `custom-board_zh.md` §4 | `Kconfig.projbuild` 加 `BOARD_TYPE_*` + `CMakeLists.txt` 加 `elseif` 分支；本项目已按此加入 `BOARD_TYPE_WAVESHARE_ESP32_S3_TOUCH_LCD_1_85_ATZGAUGE` |
| 字体/表情怎么选 | `custom-board_zh.md` §4 末 | `BUILTIN_TEXT_FONT`（本项目 20px）、`DEFAULT_EMOJI_COLLECTION`（本项目 **128px**，官方 1.85" 板用 64px，我们改大了） |
| 编译命令 | `custom-board_zh.md` §5 | `python scripts/build.py <板目录> --name <变体>`；本项目板目录 `waveshare/esp32-s3-touch-lcd-1.85-atzgauge` |
| 语音工具怎么写 | `mcp-protocol_zh.md` + `mcp-usage_zh.md` | 工具名形如 `self.xxx.yyy`；描述里要写清中文说法（我们的工具都这么写） |

## 三、我们**没有**照搬上游的地方（差异都记在 `19-与原版小智AI的差异对照.md`）

1. **不把触摸交给 `esp_lvgl_port`**：它对每次读都 `ESP_ERROR_CHECK`，休眠的 CST816S 会 NACK → 重启循环。
   因此本项目**没有 LVGL 输入设备**，按钮点击走自研的 `atz_hit_zone`（见 `18` 缺陷 #28）。
2. **刷屏条带**：上游 `SpiLcdDisplay` 用 360×20，我们改成 360×120（段数 18 → 3，见 `18` 缺陷 #36）；
   整屏 PSRAM 方案**已验证不可行**（内部 SRAM 只剩 ~13KB）。
3. **字幕**：加了"滚动 8 秒后冻结"和"静置 30 秒自动清空"（上游是一直循环滚动）。
4. **告警**：车况告警走 `Application::Alert()`（这是上游接口），但我们补了
   "告警解除 → 收回屏幕文字"（上游的 `DismissAlert()` 只在空闲态生效，会留下残影，见 `18` 缺陷 #37）。

## 四、怎么重新抓取

```powershell
# 在 D:\AtzGauge 下执行（文件名见上面表格，全部落在本目录）
$docs = @('custom-board_zh','websocket_zh','mqtt-udp_zh','mcp-protocol_zh','mcp-usage_zh',
          'glyph-push_zh','blufi_zh','code_style_zh')
foreach ($d in $docs) {
  curl.exe -s -L --max-time 40 -o "开发参考\xiaozhi-ai\$d.md" `
    "https://raw.githubusercontent.com/78/xiaozhi-esp32/main/docs/$d.md"
}
curl.exe -s -L --max-time 40 -o "开发参考\xiaozhi-ai\notify.md" `
  "https://raw.githubusercontent.com/78/xiaozhi-esp32/main/docs/notify.md"
```

> 也可先列目录看有没有新文档：
> `curl.exe -s https://api.github.com/repos/78/xiaozhi-esp32/contents/docs`

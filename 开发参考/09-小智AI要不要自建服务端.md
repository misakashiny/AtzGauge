# 小智AI 要不要自己搭建服务端？

> 结论：**基础使用不用，用官方服务器即可。只有想要稳定/无限额度/定制告警才需要自建。**

---

## 一、三档选择

### 档 1：官方服务器（免费，先试这个）✅

固件烧好后**默认就连官方服务器**，无需任何搭建：

| 方式 | 地址 | 说明 |
|---|---|---|
| 官方正式服 | **xiaozhi.me** | 注册账号即可免费用（默认 Qwen 实时模型） |
| 官方测试服 | `api.tenclass.net` + token `test-token` | 作者友情提供，免费，**请勿商用** |

流程：刷固件 → 配网 → 扫码登录 xiaozhi.me 绑定设备 → 喊"你好小智" → 能对话。

**优点**：零成本、零搭建、10 分钟可用
**缺点**：免费额度有限（长对话会断）；测试服是"友情提供"，可能不稳定或关闭

### 档 2：自建服务端（要稳定/无限用/换模型）

社区成熟方案：[xinnan-tech/xiaozhi-esp32-server](https://github.com/xinnan-tech/xiaozhi-esp32-server)
（华南理工大学刘思源教授团队主导，Python/Java/Vue，MIT 协议）

**配置要求**：

| 部署方式 | 功能 | 配置要求 |
|---|---|---|
| 最简化安装 | 智能对话、单智能体 | 全 API：**2核2G**；用本地 FunASR：2核4G |
| 全模块安装 | 多用户/多智能体/智控台 | 全 API：**2核4G**；用本地 FunASR：4核8G |

**「入门全免费」配置（不花 API 钱）**：

| 模块 | 免费方案 |
|---|---|
| ASR 语音识别 | FunASR（本地跑） |
| LLM 大模型 | glm-4-flash（智谱，免费） |
| TTS 语音合成 | EdgeTTS（微软，免费） |
| VAD | SileroVAD（本地，免费） |

支持 Docker 部署（推荐）和源码部署。

**成本**：家里旧电脑/NAS/树莓派 = ¥0；轻量云服务器 ¥50~100/月

### 档 3：为本项目定制 —— 可能根本不需要

| 需求 | 需要服务端吗 |
|---|---|
| **本地预录音频告警**（水温过高） | ❌ **完全不需要** |
| MCP 问答（"水温多少"） | ✅ 官方或自建都行 |
| notify 云端语音播报 | ✅ 需要自建 + 改代码 |

## 二、⚠️ 和车载场景直接相关的坑

**小智AI 本质是"联网语音终端"**：
- ESP32 只负责采音、推流、放音
- **推理全在云端**（ASR / LLM / TTS）
- **断网时只剩唤醒和简单本地逻辑，不能对话**

### 对车载的意义

| 需求 | 需要网络？ | 方案 |
|---|---|---|
| 水温过高告警 | ❌ **不需要** | **本地预录音频** ⭐ |
| 语音问答 | ✅ 需要 | MCP + 手机热点 |

→ **安全告警绝不能依赖网络。** 这也是为什么一直建议告警走本地音频。

车里要有网（手机热点或车载 WiFi），否则小智只能唤醒不能对话。

## 三、硬件要求核对（你的板子）

| 要求 | 官方要求 | 你的微雪 1.85 板 | 结论 |
|---|---|---|---|
| Flash | ≥ 8MB（实测建议 16MB） | **16MB** | ✅ |
| PSRAM | ≥ 2MB（实测建议 4MB） | **8MB** | ✅ |
| 离线唤醒 | 需 ESP32-**S3** 系（C3 系不支持） | **ESP32-S3** | ✅ |

| 阶段 | 做什么 |

| 1️⃣ 先试 | 刷官方小智AI 固件 → 连 xiaozhi.me → 体验对话（¥0） |
